# 📊 Day 2 – Sales Analysis using Microsoft Excel

## Overview

This repository contains my **Day 2 internship submission**, where I analyzed a sales dataset using Microsoft Excel. The project focuses on organizing data and presenting meaningful insights through pivot tables and visualizations.

* **Sales_Cleaned_Data.xlsx** – Cleaned dataset used for analysis.
* **Sales_Analysis.xlsx** – Excel workbook containing pivot tables and charts created from the dataset.

* Cleaned and organized the sales data.
* Created pivot tables to summarize information.
* Built charts and graphs for better data visualization.
* Arranged the analysis in a structured and easy-to-understand format.
* Explored sales trends using Excel's analytical features.

## Tools Used

* Charts and Graphs
* Data Cleaning Techniques

The objective of this project is to demonstrate practical Excel skills for data preparation, analysis, and visualization as part of my internship assignment.
